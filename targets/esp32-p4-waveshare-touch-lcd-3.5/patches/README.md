# Patches for managed components

`managed_components/` is regenerated by the IDF component manager and is not
version-controlled, so any fix to a managed component lives here as a patch and
must be reapplied after the component manager refreshes (e.g. after deleting
`managed_components/` or bumping `idf_component.yml`).

## espressif__esp_video-csi-bypass.patch

ESP32-P4 rev < v3.0 (the rev v1.3 silicon on these Waveshare boards) cannot do
RAW→RGB565 color conversion in the MIPI-CSI bridge. The patch forces the CSI
controller into 16-bpp pass-through (the inline ISP demosaics instead), sizes
the frame at the unpacked RAW width so the full frame is converted (not 62.5%
of the height), and restores the standard MIPI data-type filter range
[0x12, 0x2f] that the custom-depth path leaves at [0, 0] (which would drop all
RAW10 packets and yield a blank preview).

Apply from this target directory:

```sh
patch -p1 < patches/espressif__esp_video-csi-bypass.patch
```
